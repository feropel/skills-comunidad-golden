# 🔎 golden-investigacion-mercado — Guía rápida (Comunidad Golden)

**Investigación de mercado PURA**: absolutamente todo lo investigable de un producto, con fuentes.
Arranca incluso de **una sola foto**. No construye ni pauta — para el lanzamiento completo está
`golden360`, que usa esta skill como su primer bloque.

## Qué hace
| Fase | Resultado |
|---|---|
| -1 Forense | De la foto al nombre real, fabricante, **INCI** y existencia en Dropi/Shopify/mercado. Crea el expediente `PRODUCTO.json` |
| 0 Intake | 6 campos (país, forma→verbo, pago, vertical) + los 4 números de negocio → **breakeven** |
| 0.5 Reconocimiento | Qué ya existe: ficha, pauta previa, **pedidos reales** (fuente reina), archivos |
| 1 Investigación 360 | Competidores, voz del cliente con citas, **minería de comentarios multi-idioma** (YouTube/TikTok/IG/FB/Reddit/Amazon/AliExpress), anuncios activos + **dossier psicológico de 30 capas** |
| 2 Documento | **Word (.docx) real**, citado |
| 🎯 Entrega | Los **5 datos de viabilidad** (demanda, saturación, proveedor, margen, riesgo) + recomendación honesta: lanzar / condicionar / matar |

## Cómo se usa
> *"Investiga este producto: [FOTO o URL]. País: [país]."*

Dispara sola. Si falta un dato te lo pide con campo y **sigue sin frenarse** (`[PENDIENTE]`).

## Requisitos
- MCP `firecrawl` (si falta, usa búsqueda nativa) · skill `docx`.
- Apoyos opcionales: `golden-productos-ganadores`, `golden-meta-ads-analysis`, `golden-dropi-analisis`, `golden-archivos`.
- **Lanzamiento completo** (página + creativos + pauta + bot + QA) → instala `golden360`.

## Reglas que la hacen confiable
1. **Nunca inventa** — cada dato con fuente; lo no verificable se marca hipótesis.
2. **Solo productos reales** — identidad desde etiqueta/INCI; la ficha vieja es fuente contaminada.
3. **Nunca te frena** por un dato faltante.
4. **Se auto-mejora**: se califica al final de cada corrida y hornea lo aprendido.
