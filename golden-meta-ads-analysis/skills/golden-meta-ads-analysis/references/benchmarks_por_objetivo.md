# Benchmarks por objetivo de campaña + método de las 3 Q's

Extiende el análisis más allá de VENTAS COD: cubre campañas de Interacción/Mensajes, Clientes Potenciales (Formularios y Sitio Web) y Reconocimiento/Tiendas físicas, donde NO hay "compra" que llevar al P&L y por eso el benchmark es el **objetivo que da el usuario**, no el CPA breakeven.

> La metodología de las **3 Q's** está basada en el trabajo de **Felipe Vergara** (📺 https://www.youtube.com/@FelipeVergara).

## 🔒 Regla inquebrantable — fuente única de benchmarks

Las tablas de abajo son la ÚNICA fuente de verdad para los umbrales 🔴/🟡/🟢 de estas métricas. NO uses "promedios de la industria" ni cifras de conocimiento general — aunque las recuerdes, están desactualizadas o son de otro vertical.

Antes de escribir cada Estado: localiza la métrica en la tabla del tipo, compara contra el umbral EXACTO, y si la métrica no está pon `—` sin inventar umbral.

- ❌ `CTR 1.2% 🟢 (sobre el promedio de industria 1%)`
- ✅ `CTR 1.2% 🟡 (tabla: 🔴 <1% / 🟡 1-2% / 🟢 >2%)`

Para **VENTAS en COD**, el CPA breakeven calculado en unit economics manda sobre estos benchmarks genéricos; estas tablas aplican de lleno a los objetivos NO-venta.

## 🎯 Pedir el OBJETIVO del negocio (antes de analizar)

| Tipo | Pregunta |
|------|----------|
| 🛒 Ventas | Cuál es tu ROAS objetivo? (depende de tu margen) |
| 📋 CP Formularios / 🌐 CP Sitio Web | Cuál es tu CPL objetivo? |
| 💬 Interacción / Mensajes | Cuál es tu costo por conversación objetivo? |
| 🏪 Reconocimiento / Tiendas físicas | No aplica — evalúa por CPM y alcance vs periodos previos |

Si no lo sabe: **ROAS objetivo ≈ 1 / margen neto** (margen 30% → ROAS ≥ 3.3x para empatar; apunta a (1/margen)×1.5). **CPL objetivo ≈ ticket × tasa de cierre × margen × 0.3.**

Semáforo por objetivo: ROAS ≥ objetivo 🟢 / ≥ 80% 🟡 / < 80% 🔴. CPL ≤ objetivo 🟢 / ≤ 120% 🟡 / > 120% 🔴 (igual para costo por conversación).

## Estructura de diagnóstico — las 3 Q's

1. **Qué pasó?** → métricas principales (resultado) vs objetivo del usuario.
2. **Por qué pasó?** → métricas secundarias del embudo y calidad; señala el paso con el % más bajo.
3. **Qué haremos?** → acciones concretas ordenadas por urgencia según el benchmark que falló.

En VENTAS COD, "Qué haremos?" = las 3 preguntas Golden (qué pausar / qué escalar / cómo configurar y replicar) + el veredicto por CPA breakeven.

## 🛒 VENTAS — embudo y umbrales
Embudo: `Impresiones → Clics salientes → Visitas p.d. → Ver contenido → [Carrito] → Checkout → Compra`. El paso con el % más bajo es la oportunidad.

| Métrica | Benchmark |
|---------|-----------|
| ROAS | **ROAS objetivo del usuario** (en COD: CPA vs breakeven manda) |
| % Compras / Pagos iniciados | 🔴 <10% / 🟡 10-30% / 🟢 >30% |
| % Checkout / Carritos *(si hay datos)* | 🔴 <30% / 🟡 30-50% / 🟢 >50% |
| % Carritos / Ver contenido *(si hay datos)* | 🔴 <10% / 🟡 10-20% / 🟢 >20% |
| % Ver contenido / Visitas p.d. | 🔴 <60% / 🟡 60-100% / 🟢 >100% |
| % Visitas / Clics salientes | 🔴 <50% / 🟡 50-70% / 🟢 >70% |
| CTR saliente | 🔴 <1% / 🟡 1-2% / 🟢 >2% |
| % Reproducciones 3s / Impresiones | 🔴 <20% / 🟡 20-30% / 🟢 >30% |
| Tiempo promedio de reproducción | 🔴 <3s / 🟡 3-6s / 🟢 >6s |
| Frecuencia | <3 ideal / >5 saturado |
| Métricas de calidad | ABOVE_AVERAGE ideal |

Acciones: ROAS<80% objetivo → revisar margen/precio, pausar o reducir, auditar embudo. 80-100% → optimizar el paso más bajo, no pauses. ≥objetivo → escalar +20% cada 3 días. %Compras/Pagos<30% → simplificar checkout. CTR<2% → nuevos creativos. Video 3s<30% → cambiar primeros 3s. Frecuencia>5 → ampliar audiencia / rotar.

|---------|-----------|
| Costo por conversación | **objetivo del usuario** |
| Tasa de conversión a Mensajes (conversaciones / clics únicos) | 🔴 <30% / 🟡 30-50% / 🟢 >50% |
| CTR único (enlace) | 🔴 <1% / 🟡 1-2% / 🟢 >2% |
| % Reproducciones 3s / Impresiones | 🔴 <20% / 🟡 20-30% / 🟢 >30% |
| Tiempo promedio de reproducción | 🔴 <3s / 🟡 3-6s / 🟢 >6s |
| Frecuencia | <3-5 |

Acciones: tasa a mensajes<50% → CTA más específico (invitar a chatear). CTR<2% → mejorar creativo. Video 3s<30% → mejor gancho. Frecuencia alta → rotar creativos.
